NotesCopilot 是常驻 macOS 菜单栏的 AI 写作助手，深度集成 Apple Notes。本文档介绍全部功能的使用方法与配置项。

## 启动与权限

1. 启动 `NotesCopilot.app`：未配置模型时显示设置，已配置时显示 AI 面板；应用常驻菜单栏，无 Dock 图标。首次从浏览器下载的 DMG 若触发「无法检查恶意软件」提示，先点「完成」，再打开「系统设置 → 隐私与安全性」，在安全区点「仍要打开」并确认
2. 首次启动会引导授权 **辅助功能**（系统设置 → 隐私与安全性 → 辅助功能）
3. 斜杠可在 Notes 编辑区的标题行和正文触发。菜单键盘导航与关键词扩展使用已授权的辅助功能通道，无需额外开启输入监控；监听暂不可用时可点击命令。资料库与 Notes 模板另需 **完全磁盘访问权限**，错误界面提供设置和重试入口
4. **自动化**允许读取当前笔记身份以绑定安全的写回目标；系统询问是否允许控制 Notes 时，允许后才能完整使用选区加工与写回。拒绝时，面板和通用诊断页会提示打开自动化设置。

关闭窗口或看不到菜单栏图标时，重新打开 `NotesCopilot.app` 会恢复设置或 AI 面板。最小化窗口会还原，移除外接屏后窗口会移回当前屏幕。

设置侧栏底部提供 **打开 AI 面板** 和 **笔记库** 按钮。菜单栏拥挤时，图标可能被屏幕刘海遮挡；上述按钮与全局快捷键仍可使用。启动日志中的 `statusItemObscuredByNotch` 可帮助定位这一情况。

## 应用内更新

1. 菜单栏 → **检查更新…**，或打开「设置 → 通用与诊断 → 版本更新」。
2. 发现新版本时显示版本号和发布说明。点「直接下载」后显示进度，可随时取消；取消不会保留临时 `.part` 文件。
3. 下载完成后应用会校验 SHA-256，通过后把 DMG 保存到「下载」文件夹并在 Finder 中定位。校验失败或发布包缺少校验信息时会删除不完整文件并提示前往发布页。
4. 安装时将 `NotesCopilot.app` 拖入「应用程序」替换旧版本。自动检查默认每天一次，可在设置中关闭。

## 入口一：AI 面板（⇧⌘Space）

| 操作 | 说明 |
|---|---|
| `⇧⌘Space` | 任意应用内呼出/收起面板 |
| 输入问题 | 流式返回答案 |
| 写入 Notes | 回答可插入 Notes 光标处，或替换当前选中内容 |

- 面板顶部显示当前生效模型（设置中可切换），提供「新会话」与历史记录
- 连续对话携带最近 6 轮；更换笔记来源或模型配置会开始新会话
- 重启应用会恢复最近一次会话；停止生成后未完整输出也会保留。关闭「连续对话」会清空本地会话记录
- 输出可切换 Markdown 预览／原文；可关闭「跟随输出」阅读前文
- 失败、停止或截断会保留当前输出，使用「重新生成／继续生成」恢复；不完整结果不会标为已完成
- 上下文自动携带 Notes 光标前文本（有选中时优先带选中内容）

## 入口二：斜杠命令

在 **Notes 标题行或正文** 输入 `/`：

1. 自动弹出命令面板，按分组展示：
   - **AI 加工**：续写、总结、翻译、润色、解释、扩写、提取要点、拟标题
   - **Markdown 格式**：常用 MD 语法包裹
   - **模板**：本地模板，以及 Notes「Templates」文件夹中自动读取的笔记
   - **工具**：其他实用命令
2. `↑`/`↓` 选择，`⏎` 执行，`Esc` 取消
3. 命令执行前会自动删除 `/` 及过滤词

内置 AI 命令使用英文别名，可按中文名称或英文别名筛选；例如输入 `/tra` 找到翻译，或输入 `/translate` 后加空格直接执行。

Notes 编辑区和 AI 面板的提示词输入框均支持分类查询：`/templates` 列出全部模板，`/ai`、`/markdown`、`/tools` 分别列出 AI、格式和工具命令。分类后加空格可继续按名称或别名筛选，例如 `/templates 会议`；分类词本身不会执行命令。使用 `↑↓` 选择，再按 `⏎` 执行，`Esc` 关闭列表。

| 命令 | 英文别名 |
|---|---|
| 续写 | `/continue` |
| 总结 | `/summarize` |
| 自动翻译（中文译成英文，其他语言译成简体中文） | `/translate` |
| 润色 | `/polish` |
| 解释 | `/explain` |
| 扩写 | `/expand` |
| 提取要点 | `/keypoints` |
| 拟标题 | `/titles` |

`/title` 仍用于 Markdown 标题格式；自定义模板保留现有名称与别名。

设置 → 斜杠与文本扩展 → 自定义 AI 命令可创建固定提示词。命令名建议使用英文、拼音或中文，长度 1–32 个字符，不能含空格、斜杠或反斜杠，也不能与内置命令或另一条自定义命令重复。创建后输入 `/命令名` 执行；关闭「启用」可临时隐藏，删除后命令列表立即刷新。

> 上下文自动带入：有选中时带选中内容，否则取光标所在段落。

## 入口三：选区写作工具

浮钮出现后，可单击或按一次 `M` 展开同一个工具菜单。按钮旁的字母可直接按，无需组合键。

| 当前页面 | 快捷键 |
| --- | --- |
| 工具菜单 | `I` 输入自定义指令，`P` 校对，`R` 润色，`C` 精简，`S` 总结，`T` 翻译，`E` 解释 |
| 自定义指令输入框 | 正常输入文字。回车执行，`Esc` 返回工具并保留草稿。输入法组词时由输入法先处理按键 |
| 结果页 | `O` 切换原文与结果，`C` 复制当前显示的文本，`G` 重新生成或重试，`B` 换个工具 |
| 可以写回的结果 | `A` 追加到原选区末尾，`R` 替换选区。显示原文、差异或原选区失效时，写回停用 |

例如，按 `M` 打开工具，按 `T` 翻译，等译文出现后按 `C` 复制。在菜单或结果页按 `Esc` 可关闭面板。

| 位置 | 打开方式 | 结果可用于 |
|---|---|---|
| Notes 正文 | 选中文字，待选区稳定后点旁边的「Copilot 写作阅读助手」 | 对照原文、复制、替换选区、追加 |
| 其他可编辑输入框 | 在「设置 → 斜杠与文本扩展 → 选区写作工具 → 应用范围」选择「全局」，在支持的输入框内选中文字并点浮钮 | 对照原文、复制、替换原选区、追加到选区末尾 |
| 网页正文等只读文字 | 选择「全局」后，在支持文字选区的页面划选并点浮钮 | 对照原文、复制结果 |
| 提供文本服务的 macOS 应用 | 选中文字，从当前应用菜单或支持的右键菜单选「服务 → 用 NotesCopilot 处理选中文本」 | 对照原文、复制，再粘贴到所需位置 |

1. 核对选区摘录后，可选择校对、润色、精简、总结、翻译或解释。翻译按原文主要语言决定方向，简体和繁体中文译成英文，其他语言译成简体中文。要指定目标语言，按 `I` 输入「翻译成日文」等指令，再按 `⏎`。
2. 生成完成后可直接编辑结果；点「差异」查看按行对照的删除与新增。复制按钮会随当前版本改变。可用「重新生成」尝试另一稿，或「换个工具」继续处理同一段原文。关闭面板会取消正在进行的请求。
3. 在原输入框中采用生成稿时，点「替换选区」或按 `R`、点「追加」或按 `A` 都会先显示写入预览，确认后才写入。若已移动选区、改动输入框文字或切换目标，保留结果供复制。点「追加」会将结果插在选区末尾，保留原文和后续文字。Notes 另有标题、列表、颜色等格式操作。

全局浮钮出现时会临时记住所选文字。鼠标移向浮钮时，即使聊天界面重绘、选区暂时消失，仍可点开翻译、总结和复制。点「替换选区」或「追加」时会再次核对原输入框和选区。点击别处会收起浮钮，划选另一段文字会显示新的浮钮。

普通选中及打开面板仅在本机处理。点动作或提交指令后，所选文字才会随该指令发送至当前配置的模型。服务入口接收宿主提供的纯文本，用户可以在可编辑字段和只读材料中使用它。

首次安装默认「仅 Notes」，升级保留已选范围。切换到「全局」即时生效，需在系统「隐私与安全性 → 辅助功能」中允许 NotesCopilot。密码框会跳过。全局模式可临时暂停，也可维护黑名单或白名单；名单可从当前运行中的应用选择，或手动输入 bundle ID / 应用名。本机只保存应用标识，不保存选中文本。宿主仅支持导出选区时，也可从「服务」调用。将应用放入「应用程序」并打开一次，可在「系统设置 → 键盘 → 键盘快捷键 → 服务」启用服务或指定快捷键。

## URL 自动转标题超链

1. 复制一个网页 URL，在 Notes 粘贴后 **加一个空格**
2. 约 2 秒内自动变成 `[网页标题](URL)` 超链接
3. 抓取失败时保留原 URL（三级兜底：HTTP 直抓 → 共享 Cookie → 浏览器标签页）

可在设置中开关（`nc.urltitle.enabled`）。

## 模型配置

菜单栏图标 → **设置**：

模型页顶部固定显示“保存配置”按钮及当前保存状态，填写时也会尝试自动保存。保存会直接写入本机偏好设置，不访问系统钥匙串，也不会触发系统钥匙串授权弹窗。从 2.9.1 升级后如 API Key 显示为空，重新填写并保存一次。

1. 左侧选择服务商预设（DeepSeek / Kimi / 通义千问 / OpenAI / OpenRouter / 硅基流动），或自定义任意 OpenAI 兼容端点
2. 填入 API Key，点「拉取模型列表」选择模型
3. **本地模型**：启动时自动探测 Ollama (11434)、LM Studio (1234)、llama.cpp (8080)、vLLM (8000)，发现后在设置页亮起
4. 可保存多份配置，点卡片左侧圆圈切换生效配置
5. 每份配置可单独设置 **温度**（建议 0–2）和 **输出上限**（建议 256–8192 tokens）。留空时使用全局默认值，实际可用范围以服务商为准

## 模板

在 Notes 中建立名为「Templates」的文件夹，将笔记放入后即可通过 `/模板名` 使用，无需导入。文件夹名称不区分大小写，多个账户中的同名文件夹也会读取；仅使用正文可完整读取且非空的笔记。在 Notes 中修改内容、移出文件夹或删除笔记后，模板列表会自动刷新。

设置 → 模板可查看 Notes 模板、刷新读取状态，并在权限不足时重试；模板内容请在 Notes 中编辑。同名时优先使用 Notes 版本，本地版本仍保留，移除对应 Notes 模板后恢复使用本地版本。内置模板与自定义模板继续保存在本机设置中。

Templates 笔记的**第一行是模板名**，只用于列表和命令，不会写入生成文档。**第二行起是生成内容**，首个内容段落作为新文档标题，支持变量展开；模板名后的空白分隔行会跳过，其余正文空行和样式保留。只有模板名、没有生成内容的笔记不会列为模板。例如：

```text
Weekly Work Templates
{{date: yyyy-MM-dd}}周记录
本周工作内容……
```

列表显示 `Weekly Work Templates`，生成文档的标题为执行当天的日期加“周记录”，不包含模板名。

新笔记标题行和正文均可输入模板命令。Notes 模板保留生成内容中的标题、粗体、列表和多行等宽块等格式；本地模板中的 Markdown 会转换为富文本。模板需要询问或 AI 时，命令保留到展开完成后再整体替换，期间换笔记、移动光标或修改原文会取消写入。

两种来源均支持 `{{date}}`、`{{selection}}`、`{{ask:问题}}`、`{{ai:指令}}` 等变量。AI 模板使用当前选区或光标段落，生成过程中开始新会话或停止会取消模板。

## 常见问题

**Q：斜杠命令不出现？**
查看 AI 面板的笔记上下文提示，或设置 → 通用与诊断。先确认当前构建已获「辅助功能」权限；重建或更换签名后，旧授权可能不适用于新构建。若提示笔记身份读取被拒绝，再到「自动化」允许 NotesCopilot 控制 Notes。两项权限正常后，再检查斜杠开关，并在 Notes 正文输入 `/`。若方向键无响应，查看“命令键盘导航与关键词扩展”是否显示监听已启动；键盘监听使用辅助功能授权，无需额外开启输入监控。

**Q：选中后看不到写作工具？**
在正文或可编辑输入框中选取文字并短暂停留。检查辅助功能权限及「设置 → 斜杠与文本扩展」中的选区开关。在其他应用里还需选择「全局」。密码框和未提供可读选区的自绘控件不会弹出浮钮。展开后若提示无法确认笔记，检查 Notes 自动化权限，再点「重新读取选区」。

**Q：AI 结果没有插入 Notes？**
插入前 Notes 必须是前台应用（面板会自动切回）；另外确认光标位于正文编辑区。

**Q：本地模型探测不到？**
确认本地服务已启动且为 OpenAI 兼容端点（如 Ollama 需 `OLLAMA_ORIGINS` 允许访问）；也可在设置中手动填 `http://localhost:11434/v1`。

**Q：URL 没有转成超链？**
部分网站反爬会失败（保留原 URL 不受影响）；内网地址不支持自动抓取。

## 笔记库

搜索输入防抖 300ms 后执行，支持中文中段与多个关键词，可与文件夹或标签组合。搜索框可一键清空，最近搜索最多保留 8 条并可清空；标题和摘要高亮当前关键词，正文可在 Markdown 预览与原文间切换。刷新和排序保留筛选与当前笔记；加载期间禁用复制和导出，避免标题与正文错配。首次索引在后台执行。附件、图片、表格等无法完整还原时会明确提示，导出的 Markdown 保留警告；不完整正文不能直接送入 AI。

## 本地验证

`scripts/run-tests.sh` 运行十套回归，网络请求使用模拟响应，资料库使用合成 SQLite。`scripts/check-ui.sh` 使用隔离配置渲染 25 种原生界面，包含「仅 Notes」和「全局」两种设置。跨进程替换和系统服务验收见[写作工具调研](WRITING-TOOLS.md)。
