# 使用说明

NotesCopilot 是常驻 macOS 菜单栏的 AI 写作助手，深度集成 Apple Notes。本文档介绍全部功能的使用方法与配置项。

## 启动与权限

1. 启动 `NotesCopilot.app`：未配置模型时显示设置，已配置时显示 AI 面板；应用常驻菜单栏，无 Dock 图标
2. 首次启动会引导授权 **辅助功能**（系统设置 → 隐私与安全性 → 辅助功能）
3. 斜杠仅在 Notes 正文触发。菜单键盘导航与关键词扩展使用已授权的辅助功能通道，无需额外开启输入监控；监听暂不可用时可点击命令。资料库与模板导入另需 **完全磁盘访问权限**，错误界面提供设置和重试入口
4. **自动化**允许读取当前笔记身份以绑定安全的写回目标；系统询问是否允许控制 Notes 时，允许后才能完整使用选区加工与写回。拒绝时，面板和通用诊断页会提示打开自动化设置。

关闭窗口或看不到菜单栏图标时，重新打开 `NotesCopilot.app` 会恢复设置或 AI 面板。最小化窗口会还原，移除外接屏后窗口会移回当前屏幕。

设置侧栏底部提供 **打开 AI 面板** 和 **笔记库** 按钮。菜单栏拥挤时，图标可能被屏幕刘海遮挡；上述按钮与全局快捷键仍可使用。启动日志中的 `statusItemObscuredByNotch` 可帮助定位这一情况。

## 入口一：AI 面板（⇧⌘Space）

| 操作 | 说明 |
|---|---|
| `⇧⌘Space` | 任意应用内呼出/收起面板 |
| 输入问题 | 流式返回答案 |
| 写入 Notes | 回答可插入 Notes 光标处，或替换当前选中内容 |

- 面板顶部显示当前生效模型（设置中可切换），提供「新会话」与历史记录
- 连续对话携带最近 6 轮；更换笔记来源或模型配置会开始新会话
- 输出可切换 Markdown 预览／原文；可关闭「跟随输出」阅读前文
- 失败、停止或截断会保留当前输出，使用「重新生成／继续生成」恢复；不完整结果不会标为已完成
- 上下文自动携带 Notes 光标前文本（有选中时优先带选中内容）

## 入口二：斜杠命令

在 **Notes 正文** 输入 `/`：

1. 自动弹出命令面板，按分组展示：
   - **AI 加工**：续写、总结、翻译、润色、解释、扩写、提取要点、拟标题
   - **Markdown 格式**：常用 MD 语法包裹
   - **模板**：本地模板，以及从 Notes「Templates」文件夹显式导入的模板
   - **工具**：其他实用命令
2. `↑`/`↓` 选择，`⏎` 执行，`Esc` 取消
3. 命令执行前会自动删除 `/` 及过滤词

内置 AI 命令使用英文别名，可按中文名称或英文别名筛选；例如输入 `/tra` 找到翻译，或输入 `/translate` 后加空格直接执行。

| 命令 | 英文别名 |
|---|---|
| 续写 | `/continue` |
| 总结 | `/summarize` |
| 翻译 | `/translate` |
| 润色 | `/polish` |
| 解释 | `/explain` |
| 扩写 | `/expand` |
| 提取要点 | `/keypoints` |
| 拟标题 | `/titles` |

`/title` 仍用于 Markdown 标题格式；自定义模板保留现有名称与别名。

> 上下文自动带入：有选中时带选中内容，否则取光标所在段落。

## 入口三：选中加工条

在 Notes 中 **选中文本**（≥ 若干字符），悬浮加工条自动出现在选区附近：

### AI 按钮（第一行）
润色 · 总结 · 翻译 · 解释 · 精简 —— 点击即对选区执行，结果显示在面板中，随后可：

- **替换选区**：用结果覆盖原文本
- **追加**：结果追加到选区后面

### 自定义指令（第二行）
- 点击输入框（此时会临时把焦点切给面板），输入任意指令
- `⏎` 执行，例如：`改写成邮件语气`、`把这段话翻译成英文并保留术语`
- 执行后同样可替换 / 追加

### 格式按钮（常用项 + 更多格式）
| 5 | 5 | 3 |
|---|---|---|
| 标题 · 小标题 · 副标题 · 正文 · 等宽 | 斜体 · 下划线 · 删除线 · 颜色 · 圆点列表 | 短划线 · 编号列表 · 块引用 |

- 从 Notes「格式」菜单读取，中英文菜单均支持；常用项直接显示，其余在「更多格式」中选择
- 点击后面板保持展开，可对同一选区连续叠加多种格式
- 「颜色」会打开系统颜色面板

### 关闭加工条
点击选区外、按 `Esc`、或选区变化时自动收起；可在设置中关闭整个功能。

## URL 自动转标题超链

1. 复制一个网页 URL，在 Notes 粘贴后 **加一个空格**
2. 约 2 秒内自动变成 `[网页标题](URL)` 超链接
3. 抓取失败时保留原 URL（三级兜底：HTTP 直抓 → 共享 Cookie → 浏览器标签页）

可在设置中开关（`nc.urltitle.enabled`）。

## 模型配置

菜单栏图标 → **设置**：

模型页顶部固定显示“保存配置”按钮及当前保存状态，填写时也会尝试自动保存。若钥匙串要求重新授权，编辑内容会保留；点击“保存配置”或恢复卡中的“授权钥匙串并保存”，由系统处理认证。取消后可继续编辑草稿。授权保存期间等待系统提示完成或取消，避免同时编辑同一份配置。

1. 左侧选择服务商预设（DeepSeek / Kimi / 通义千问 / OpenAI / OpenRouter / 硅基流动），或自定义任意 OpenAI 兼容端点
2. 填入 API Key，点「拉取模型列表」选择模型
3. **本地模型**：启动时自动探测 Ollama (11434)、LM Studio (1234)、llama.cpp (8080)、vLLM (8000)，发现后在设置页亮起
4. 可保存多份配置，点卡片左侧圆圈切换生效配置

## 模板

模板保存在 NotesCopilot 本机设置中，支持 `{{date}}`、`{{selection}}`、`{{ask:问题}}`、`{{ai:指令}}` 等变量。

要复用 Notes 笔记：建立名为「Templates」的文件夹 → 设置 → 模板 →「导入 Templates 文件夹」。导入只新增可完整读取、非空且名称不重复的模板，不覆盖已有内容；导入后独立编辑，不持续同步。AI 模板使用当前选区或光标段落，生成过程中开始新会话或停止会取消模板。

## 设置项一览

| Defaults Key | 说明 | 默认 |
|---|---|---|
| `nc.kw.enabled` | 关键词文本扩展 | false |
| `nc.slash.global` | Notes 正文斜杠命令 | true |
| `nc.md.enabled` | Markdown 格式命令 | true |
| `nc.selai.enabled` | 选中加工条 | true |
| `nc.urltitle.enabled` | URL 转标题超链 | true |
| `nc.model` | 生效模型配置 | - |
| `nc.sys` | System Prompt | 内置 |
| `nc.temp` | 生成温度 | 模型默认 |
| `nc.continuous` | 连续对话模式（最近 6 轮） | true |

## 常见问题

**Q：斜杠命令不出现？**
查看 AI 面板的笔记上下文提示，或设置 → 通用与诊断。先确认当前构建已获「辅助功能」权限；重建或更换签名后，旧授权可能不适用于新构建。若提示笔记身份读取被拒绝，再到「自动化」允许 NotesCopilot 控制 Notes。两项权限正常后，再检查斜杠开关，并在 Notes 正文输入 `/`。若方向键无响应，查看“命令键盘导航与关键词扩展”是否显示监听已启动；键盘监听使用辅助功能授权，无需额外开启输入监控。

**Q：选中后加工条不弹出？**
加工条依赖辅助功能读取 Notes 选区，并通过自动化读取当前笔记身份；确认 Notes 是前台应用且已在正文中选中文字。短暂快照失败后会重试同一选区，恢复权限后无需重新选择。仍不出现时查看面板提示及日志中是否有「选中加工面板弹出」记录。

**Q：AI 结果没有插入 Notes？**
插入前 Notes 必须是前台应用（面板会自动切回）；另外确认光标位于正文编辑区。

**Q：本地模型探测不到？**
确认本地服务已启动且为 OpenAI 兼容端点（如 Ollama 需 `OLLAMA_ORIGINS` 允许访问）；也可在设置中手动填 `http://localhost:11434/v1`。

**Q：URL 没有转成超链？**
部分网站反爬会失败（保留原 URL 不受影响）；内网地址不支持自动抓取。

## 笔记库

正文搜索支持中文中段与多个关键词，可与文件夹或标签组合。刷新和排序保留筛选与当前笔记；加载期间禁用复制和导出，避免标题与正文错配。首次索引在后台执行。附件、图片、表格等无法完整还原时会明确提示，导出的 Markdown 保留警告；不完整正文不能直接送入 AI。

## 本地验证

`scripts/run-tests.sh` 运行九套回归，网络请求使用模拟响应，资料库使用合成 SQLite。`scripts/check-ui.sh` 使用隔离配置渲染十四种原生界面，输出到 `build/ui-smoke`。这些检查不代替实际 macOS 权限授权后的 Notes 交互验收。
