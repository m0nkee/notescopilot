## 启动与权限

1. 启动 `NotesCopilot.app`（无 Dock 图标，看菜单栏 📝 图标）
2. 首次启动会引导授权 **辅助功能**（系统设置 → 隐私与安全性 → 辅助功能）
3. 如需在任意应用响应 `/` 按键，可另授 **输入监控**；不授权也能用（自动降级为 AX 轮询通道，仅需辅助功能）

## 入口一：AI 面板（⇧⌘Space）

| 操作 | 说明 |
|---|---|
| `⇧⌘Space` | 任意应用内呼出/收起面板 |
| 输入问题 | 流式返回答案 |
| 写入 Notes | 回答可插入 Notes 光标处，或替换当前选中内容 |

- 面板顶部显示当前生效模型（设置中可切换）
- 上下文自动携带 Notes 光标前文本（有选中时优先带选中内容）

## 入口二：斜杠命令

在 **Notes 正文** 输入 `/`：

1. 自动弹出命令面板，按分组展示：
   - **AI 加工**：润色 / 总结 / 翻译 / 解释 / 精简
   - **Markdown 格式**：常用 MD 语法包裹
   - **模板**：你在 Notes「Templates」文件夹里的笔记
   - **工具**：其他实用命令
2. `↑`/`↓` 选择，`⏎` 执行，`Esc` 取消
3. 命令执行前会自动删除 `/` 及过滤词

> 上下文自动带入：有选中时带选中内容，否则取光标所在段落。

## 入口三：选中加工条

在 Notes 中 **选中文本**（≥ 若干字符），悬浮加工条自动出现在选区附近：

### AI 按钮（第一行）
润色 · 总结 · 翻译 · 解释 · 精简 —— 点击即对选区执行，结果显示在面板中，随后可：

- **替换选区**：用结果覆盖原文本
- **追加**：结果追加到选区后面

### 自定义指令（第二行）
- 点击输入框（此时会临时把焦点切给面板），输入任意指令
- `⏎` 执行，例如：`改写成邮件语气`、`把这段话翻译成英文并保留术语`
- 执行后同样可替换 / 追加

### 格式按钮（后三行，13 项）
| 5 | 5 | 3 |
|---|---|---|
| 标题 · 小标题 · 副标题 · 正文 · 等宽 | 斜体 · 下划线 · 删除线 · 颜色 · 圆点列表 | 短划线 · 编号列表 · 块引用 |

- 与 Notes「格式」菜单完全对应，**动态枚举**（Notes 更新菜单后自动跟随）
- 点击后面板保持展开，可对同一选区连续叠加多种格式
- 「颜色」会打开系统颜色面板

### 关闭加工条
点击选区外、按 `Esc`、或选区变化时自动收起；可在设置中关闭整个功能。

## URL 自动转标题超链

1. 复制一个网页 URL，在 Notes 粘贴后 **加一个空格**
2. 约 2 秒内自动变成 `[网页标题](URL)` 超链接
3. 抓取失败时保留原 URL（三级兜底：HTTP 直抓 → 共享 Cookie → 浏览器标签页）

可在设置中开关（`nc.urltitle.enabled`）。

## 模型配置

菜单栏图标 → **设置**：

1. 左侧选择服务商预设（DeepSeek / Kimi / 通义千问 / OpenAI / OpenRouter / 硅基流动），或自定义任意 OpenAI 兼容端点
2. 填入 API Key，点「拉取模型列表」选择模型
3. **本地模型**：启动时自动探测 Ollama (11434)、LM Studio (1234)、llama.cpp (8080)、vLLM (8000)，发现后在设置页亮起
4. 可保存多份配置，点卡片左侧圆圈切换生效配置

## 模板

模板复用 Notes 原生机制：在 Notes 中建立名为「Templates」的文件夹，其中的每篇笔记即一个模板。斜杠命令面板的「模板」分组会列出它们，选择后插入。

## 设置项一览

| Defaults Key | 说明 | 默认 |
|---|---|---|
| `nc.kw.enabled` | 斜杠命令总开关 | true |
| `nc.slash.global` | 全局按键监听（需输入监控） | true |
| `nc.md.enabled` | Markdown 格式命令 | true |
| `nc.selai.enabled` | 选中加工条 | true |
| `nc.urltitle.enabled` | URL 转标题超链 | true |
| `nc.model` | 生效模型配置 | - |
| `nc.sys` | System Prompt | 内置 |
| `nc.temp` | 生成温度 | 模型默认 |
| `nc.continuous` | 连续对话模式 | false |

## 诊断与日志

```bash
tail -f ~/Library/Logs/NotesCopilot-debug.log
```

日志覆盖：权限预检、面板弹出、命令执行、格式应用、URL 抓取等关键链路，排查问题先看这里。

## 常见问题

**Q：斜杠命令不出现？**
确认已在系统设置授权「辅助功能」；若已授权，检查设置中斜杠开关，并查看日志中的权限预检结果。

**Q：选中后加工条不弹出？**
加工条依赖辅助功能读取 Notes 选区；确认 Notes 是前台应用且选中文本足够长。仍不出现时看日志是否有「选中加工面板弹出」记录。

**Q：AI 结果没有插入 Notes？**
插入前 Notes 必须是前台应用（面板会自动切回）；另外确认光标位于正文编辑区。

**Q：本地模型探测不到？**
确认本地服务已启动且为 OpenAI 兼容端点（如 Ollama 需 `OLLAMA_ORIGINS` 允许访问）；也可在设置中手动填 `http://localhost:11434/v1`。

**Q：URL 没有转成超链？**
部分网站反爬会失败（保留原 URL 不受影响）；内网地址不支持自动抓取。
