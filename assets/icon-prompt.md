# NotesCopilot 图标生成记录

生成方式：内置 imagegen。初稿使用透明背景；最终稿改为满幅不透明米白底，由 macOS 负责应用图标的圆角遮罩。

## 初稿

```text
Use case: logo-brand
Asset type: finished macOS application icon for NotesCopilot, an Apple Notes writing companion.
Primary request: Create one exceptionally simple, polished and distinctive app icon. A warm ivory rounded-square macOS tile, with a single bold graphite outline of a little note page with a folded corner, two short graphite writing strokes, and one small golden-yellow four-point glint that merges elegantly with the page's upper-right corner. The silhouette must remain clear at 32 pixels.
Style: precise geometric graphic design, flat vector-like shapes, restrained macOS app-icon craftsmanship, very subtle depth on the ivory tile only. Thick consistent rounded strokes. Calm, useful, intelligent.
Composition: one centered icon, straight-on view, large mark and generous breathing room, square 1024x1024 canvas. The ivory rounded-square tile fills roughly 88 percent of the canvas width with a consistent transparent margin.
Constraints: transparent background outside the tile, fully opaque tile interior. No text, no letters, no wordmark, no watermark, no mockup, no extra objects, no scene, no decorative patterns, no gradients inside the mark, no thin details. Output only the finished standalone icon.
```

## 最终编辑

```text
Use case: precise-object-edit
Input image: edit target, the NotesCopilot app icon.
Change only the background treatment to prepare a clean modern macOS app icon. Preserve the graphite note page outline, the two writing lines, and the golden four-point glint exactly in style and proportion. Enlarge this same central mark a little so it spans about 64 percent of canvas width. Replace the entire rounded ivory tile, its shadows, its beveled edge, and the transparent margin with a single completely flat, solid, warm ivory background (#FAF7EE) that fills the entire square canvas from edge to edge. The image must be a fully opaque square: no rounded canvas corners, no outer transparent pixels, no frame, no tile edge, no padding outside the background. macOS will provide its own rounded mask. Keep the mark centered. No text, no new elements, no additional shadows. Output only the finished square app-icon artwork.
```
